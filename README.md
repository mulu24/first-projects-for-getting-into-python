# 🐍 Python & Probability Foundations: Core Simulations

A hands-on portfolio exploring core Python programming mechanics and statistical concepts through three interactive Monte Carlo simulations and probability models. 

This repository demonstrates practical Python usage—control flow, data structures, modular functions, and data visualization using `matplotlib`—while proving foundational principles of probability theory.
